# 行间 - 列车路径规划

在两站之间找用时最短或里程最短的列车方案，可以限制换乘次数、最少换乘时间、最早出发时间和最晚到达时间。时刻表来自路路通的离线数据库，开行状态和票价向 12306 查询。

## 功能

- 站名、拼音、首字母和电报码都能用来找车站。
- 出发日期可选今天起 14 天，最晚到达日期最多晚 4 天，可设最早出发和最晚到达时刻。
- 最多换乘 0–8 次，最少换乘时间 0–720 分钟。
- 按G、D、C、S、Z、N、V、T、K、Y等车次类型筛选，另有“仅普速”预设，包含Z、N、V、Y及过渡期的T、K、无字头车次。
- 同城换乘默认开启，默认 60 分钟，可按站对调整或移除。
- 可切换用时最短/里程最短，可查最低票价，可开严格校验。
- 查询条件存在 URL 片段里，复制链接即可分享。

## 工作方式

```text
浏览器
├─ app.mjs      页面、表单、IndexedDB；网络请求在主线程发出
└─ worker.mjs   解析时刻表，调用 WASM 搜索器，逐段核验开行

Vercel Functions
├─ /api/version             当前时刻表版本
├─ /api/database            时刻表数据包
├─ /api/service-calendar    12306 开行日历
├─ /api/fares               12306 最低票价
└─ /api/warm                Cron 预热
```

浏览器不能直接请求路路通和 12306，所以由 Vercel 函数取回或转发。搜索和核验都在浏览器里完成，服务端只负责取数据和转发。

## 搜索口径

- 用时 = 最终到达时刻 − 第一程实际上车时刻，含换乘等待，不含上车前等待。
- 里程最短只用里程完整的车次；里程相同时比用时。
- 默认同站换乘。开启同城换乘后，每次换乘最多跨一次站，时间是固定值。
- 时刻表只有时分，跨日按时间回绕和区间速度上限推算。
- 离线数据里的有效期不等于实际开行，每段都按始发日期核验。停运的剔除后重搜，核验失败不输出方案。
- 12306 未收录的车次默认按离线规则判断并标注，严格校验时排除。
- 票价是最低席位价格，不是实时余票。

## 部署

1. 推到 GitHub，在 Vercel 导入。`vercel.json` 已配好构建、输出、区域和 Cron。仓库里的 Actions 负责更新时刻表数据。
2. 添加环境变量 `CRON_SECRET`，供 `/api/warm` 校验。
3. 可选：12306 拒绝 Vercel 出口地址时，部署 `worker/` 里的 Cloudflare Worker 中转，并配置 `RELAY_URL`、`RELAY_SECRET`。

## 本地开发

```sh
npm install
npm run dev     # http://127.0.0.1:5173/
npm test
```

需要 Node 22 或更高版本。本地构建不带 BotID，首次打开会下载时刻表数据包。改搜索器后用 `npm run build:wasm` 重新编译 WASM。

## 目录

| 路径 | 作用 |
| --- | --- |
| `web/` | 页面、Worker、搜索器、核验、缓存 |
| `lib/` | 时刻表解析、数据同步、12306 接口、BotID |
| `api/` | Vercel Functions |
| `router-wasm/` | Rust 搜索器 |
| `scripts/` | 打包、本地服务器、数据同步 |
| `worker/` | Cloudflare Worker 中转 |
| `tests/` | Node 测试 |
